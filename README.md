 Website Portofolio pribadi yang saya buat ini merupakan hasil dari penugasan untuk memenuhi Ujian Tengah Semester mata kuliah Pemrograman Berbasis Platform, yang diampu oleh Bapak Rifki Abdillah, S.Tr.T., M.kom.

 Web ini berisikan 3 halaman utama yaitu,
   - Halaman 1: "Home page" berisikan tentang saya dan juga foto profil,
   - Halaman 2: "Portofolio" berisikan tentang project dan juga riwayat pendidikan,
   - Halaman 3: "Hobi" berisikan tentang hobi saya.

Portofolio ini dibuat dengan menggunakan:
  - Html sebagai pondasi utama halaman,
  - Css untuk melengkapi efek animasi interaksi dan gaya khusus yang tidak disediakan di tailwind,
  - Tailwind CDN sebagai Framework utilitas CSS agar tidak membuat CSS secara manual.

Fitur utama:
  - Navbar dengan menu yang dapat menyesuaikan dengan dekstop atau mobile,
  - Home page yang menampilkan tentang saya dan juga foto profil yang dapat menyesuaikan dengan dekstop atau mobile,
  - Profile page yang menampilkan foto foto project yang telah saya buat dan juga riwayat pendidikan yang dapat menyesuaikan dengan dekstop atau mobile,
  - Hobi page yang dapat menampilkan beberapa foto hobi saya dan dapat dihover dengan efek animasi slideshow yang dapat menyesuaikan dengan dekstop atau mobile,
  - Menu mobile hamburger yang dapat terhubung ke beberapa menu seperti home, portofolio, dan juga hobi,
  - Footer yang dapat menambilkan mengenai contact atau sosial media saya dan dapat terhubung langsung.
  - Desain yang responsive dapat digunakan di berbagai perangkat.
